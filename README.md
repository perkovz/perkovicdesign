# Perkovic Design Studio

Marketing site for Perkovic Design Studio (perkovicdesign.com), built from the v3 "Beautiful world" design by Perks Principal (Figma file `yYlAejAdIjD48nB8odzQgn`: desktop `17:20`, tablet `32:20`, mobile `19:20`, menu sheet `33:20`, components `37:24`, motion spec `23:20`).

## Stack

- Next.js (App Router) + React + TypeScript, static output
- Plain CSS with custom properties (`src/app/globals.css`) for exact token and motion control
- `next/font/google`: Fraunces (upright, optical size axis, weights 400 and 600 used) and Inter (400, 500, 600)

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm run start
npm run lint
npx tsc --noEmit
```

## Where things live

| Path | What |
| --- | --- |
| `src/content/site.ts` | All visible copy, links and placeholders |
| `src/content/copy-data.json` | FAQ (13), six weeks and pricing copy exported from the design |
| `src/content/vine.ts` | Vine geometry, generated by `scripts/gen_vine.py` from the design's `vine.py` |
| `src/components/` | Nav and menu sheet, hero art (pointer depth), vine, FAQ accordion, motion controller |
| `src/lib/motion.ts` | Vine timing (nodes fire as the 1.4s ease-in-out stroke passes 6.6 / 22.7 / 43 / 64.1 / 85.4 / 100%) |

## Motion summary

- Hero entrance on load (CSS only, ends near 850ms), 7s ambient sway, pointer depth (2 to 4px, under 1deg) on fine pointers at 1024px and up
- Sticky glass nav deepens after 24px of scroll
- Scroll reveals play once at about 18% visibility, first 4 siblings staggered by 70ms
- Vine draws when 35% of the panel is visible; hovering or focusing a week warms the node and scales its leaf to 1.06
- FAQ accordion 240ms, item 1 open by default; menu sheet with focus trap, Esc, backdrop close and scroll lock
- `prefers-reduced-motion`: 150ms opacity-only fades, no sway, depth, parallax or lift; vine shown fully drawn
